# We Raise Hope

Official website for **We Raise Hope Inc.** — a U.S. 501(c)(3) public charity (EIN 99-2747198) supporting locally led healthcare, education, clean water, and livelihood programs in rural Nepal.

## Develop

```bash
npm install
cp .env.example .env.local
npm run dev
```

See [LAUNCH.md](./LAUNCH.md) for assets checklist, Givebutter, Candid, Charity Navigator, and DNS steps.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Givebutter donation embeds
